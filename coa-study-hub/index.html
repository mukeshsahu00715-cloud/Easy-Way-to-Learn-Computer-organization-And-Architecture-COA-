Stage: 1. Fetch Instruction
PC (Prog Counter) 0x004
MAR (Mem Address) 0x004
MDR / MBR LOAD R1, [100]
IR (Instruction) LOAD R1, [100]
AC / Registers R1 = 42
Step 1 (Fetch): The Program Counter (PC) holds the address of the next instruction (0x004). This address is transferred to the Memory Address Register (MAR) via the address bus.
